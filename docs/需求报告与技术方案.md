# ZViewer 需求报告与技术方案

> 基于 Tauri 2.x 的跨平台精美看图软件

---

# 第一部分：需求报告

## 1. 项目概述

开发一款**精美、快速**的桌面看图软件，以毛玻璃现代 UI 呈现，核心特色是**跨同级文件夹无缝浏览**，配合完整的快捷键体系，让键盘党流畅看图。

- **目标平台**：Windows 优先（架构上保持跨平台能力）
- **技术形态**：Tauri 2.x（Rust 后端 + Web 前端）

## 2. 功能需求

### 2.1 图片格式支持

| 类别 | 格式 | 说明 |
|------|------|------|
| 常见格式 | JPG、PNG、GIF、WebP、BMP、ICO、SVG、AVIF | 浏览器原生解码（AVIF 需 Chromium ≥85） |
| 静态 Rust 通道 | TIFF | Chromium 不支持，Rust 解码 → JPEG |
| 相机 RAW | CR2/CR3、NEF、ARW、DNG 等 | 内嵌预览快显 + demosaic 全量替换 |
| 动画格式 | GIF、APNG、动态 WebP | 原生 `<img>` 播放，**逐帧控制**（播放/暂停、上一帧/下一帧）按需拆帧 |

### 2.2 浏览逻辑（核心特色）

- 图片按**系统资源管理器顺序**排列（自然数排序，如 `1, 2, 10` 而非 `1, 10, 2`）
- 同级文件夹按系统顺序排列
- **无缝跨文件夹**：当前文件夹翻到最后一张后，自动跳转到下一个文件夹的第一张；向前翻同理
- **全局边界提醒**：
  - 第一个文件夹的第一张继续向左翻 → 提示「已经是第一张」
  - 最后一个文件夹的最后一张继续向右翻 → 提示「已经是最后一张」

### 2.3 图片变换

- 滚轮缩放（以鼠标位置为中心）
- 旋转（90° 步进）
- 镜像翻转（水平/垂直）
- 1:1 实际大小
- 适应窗口
- 切换图片时重置为默认「适应窗口」状态

### 2.4 幻灯片播放

- 自动轮播，从当前图片开始
- 可调播放间隔（2s / 5s / 10s / 自定义）
- 播放中同样遵循跨文件夹无缝衔接逻辑
- 播放到全局最后一张时自动停止并提醒

### 2.5 快捷键方案（经典方向键方案）

| 按键 | 功能 |
|------|------|
| ← / → | 上一张 / 下一张（跨文件夹无缝衔接） |
| ↑ / ↓ | 放大 / 缩小图片（以图片中心为锚点） |
| PageUp / PageDown | 直接跳转到上一个 / 下一个同级文件夹 |
| 滚轮 | 缩放（以鼠标为中心） |
| 空格 | 幻灯片播放 / 暂停 |
| R / Shift+R | 向右 / 向左旋转 90° |
| H / V | 水平 / 垂直翻转 |
| 1 | 实际大小（1:1） |
| 0 | 适应窗口 |
| F 或 F11 | 无边框沉浸模式切换 |
| T | 窗口置顶切换 |
| Esc | 退出沉浸模式 / 退出软件 |

### 2.6 窗口行为

- **无边框沉浸模式**：隐藏标题栏与所有 UI，纯黑背景看图，鼠标移动时浮动显示工具条
- **窗口置顶**：一键将窗口置于最前

### 2.7 启动与系统集成

- **双击图片直接打开**：安装时注册为图片格式默认打开方式（用户可选）
- **右键菜单集成**：资源管理器右键菜单添加「用 ZViewer 打开」

## 3. UI 需求（现代毛玻璃风格）

- 主界面：深色背景，图片居中最大化显示
- 工具栏：半透明磨砂（毛玻璃）浮条，圆角，悬停显示，闲置自动隐藏
- 信息条：底部毛玻璃浮条显示 `文件名 | 尺寸 | 大小 | 当前位置 3/128 | 文件夹名`
- 边界提醒：居中毛玻璃 Toast 提示「已经是第一张 / 最后一张」，1.5s 淡出
- 动画：图片切换淡入淡出、工具栏滑入滑出，过渡时长 ≤ 200ms，不拖沓
- 幻灯片模式：UI 完全隐藏，仅图片轮播

## 4. 非功能需求

| 项目 | 指标 |
|------|------|
| 启动速度 | 冷启动到显示首图 ≤ 1.5s |
| 切换速度 | 相邻已缓存图片切换 ≤ 50ms，未缓存 ≤ 300ms |
| 内存 | 缓存前后各 3 张解码结果，大图自动降采样，峰值内存可控 |
| 包体积 | 安装包 ≤ 15MB（相比 Electron 方案小一个数量级） |
| 流畅度 | 缩放/平移 60fps |

## 5. 明确不做的功能（本期范围外）

- 图片编辑（裁剪、调色、标注）
- 文件操作（删除、复制、移动、重命名、设壁纸）
- EXIF 信息面板
- 缩略图预览条
- 自定义快捷键
- 窗口大小位置记忆
- 云同步、图库管理
- 视频播放
- 平滑缩放动画（zoom 缓动易引入迟滞感）

# 第二部分：技术方案

## 6. 技术栈选型

| 层 | 技术 | 选型理由 |
|----|------|----------|
| 应用框架 | **Tauri 2.x** | Rust 后端性能强，包体积小，原生 WebView2 渲染 |
| 前端 | **Vanilla TypeScript + Vite** | 无框架运行时开销，启动最快；本项目 UI 元素少，无需重型框架 |
| 包管理 | **pnpm** | 磁盘占用小、安装快、monorepo 友好 |
| 毛玻璃 | CSS `backdrop-filter: blur()` | WebView2（Chromium 内核）原生支持，零成本实现 |
| 常见图解码 | WebView 原生 `<img>` | JPG/PNG/GIF/WebP/SVG 由浏览器内核直接渲染，免费且快 |
| RAW 解码 | Rust 端 `rawler` crate | 纯 Rust、维护活跃、覆盖主流相机 RAW 格式 |
| 动画逐帧 | Rust 端 `image` crate（gif/png/webp codec） | 解码为帧序列，前端 canvas 逐帧控制 |
| 系统顺序排序 | Rust `natord` crate | 等价 Windows 资源管理器 `StrCmpLogicalW` 自然排序 |
| 文件关联 | Tauri bundle `fileAssociations` + NSIS | 官方安装器原生支持 |
| 窗口控制 | Tauri Window API | 无边框、全屏、置顶均为内置能力 |

### 备选方案说明

- 若 `rawler` 对某些 RAW 格式覆盖不足 → 换 `libraw-rs`（LibRaw 绑定，覆盖最全，但引入 C 依赖）
- 若后续 UI 复杂度上升 → 前端可平滑迁移到 Svelte（同样轻量）

### 职责划分原则

- **前端**：所有 UI、交互、快捷键、CSS 动画、变换状态（缩放/旋转/翻转纯前端实现，零 IPC 开销）
- **Rust 后端**：一切涉及文件系统和重解码的工作——目录枚举、排序、RAW 解码、动画拆帧、预加载缓存

## 8. 关键实现方案

### 8.1 跨文件夹浏览模型

启动时建立全局浏览模型：

```rust
// Rust 后端核心数据结构
struct BrowseModel {
    parent_dir: PathBuf,           // 父目录
    folders: Vec<PathBuf>,         // 同级文件夹（含自身），natord 自然排序
    current_folder: usize,         // 当前文件夹索引
    images: Vec<ImageEntry>,       // 当前文件夹内图片，自然排序
    current_image: usize,          // 当前图片索引
}
```

- `next_image()`：到最后一张时 → 切到 `current_folder + 1` 的第一张；已是最后文件夹 → 返回边界事件，前端弹 Toast
- `prev_image()`：同理反向处理
- `jump_folder(direction)`：PageUp/PageDown 直接切换文件夹索引并加载该文件夹第一张
- 图片列表过滤：按支持的扩展名白名单过滤，枚举时仅取文件名，解码延迟到需要时

### 8.2 预加载缓存策略

```
切换图片时：
  1. 命中缓存 → 立即显示（≤50ms）
  2. 未命中 → 同步解码当前张，同时后台线程池预解码 前3张 + 后3张
  3. 缓存容量上限（如 8 张），LRU 淘汰
  4. 单张解码结果 > 阈值（如 8000×6000）时降采样到屏幕 2 倍尺寸缓存
```

跨文件夹边界处：预加载自动延伸，覆盖下一文件夹的前 3 张，保证无缝衔接流畅。

### 8.3 图片加载通道

| 图片类型 | 通道 | 说明 |
|----------|------|------|
| 常见格式 | `convertFileSrc()` → `<img src>` | Tauri asset 协议直接读本地文件，WebView 原生解码，零拷贝 |
| RAW | Rust 解码 → RGBA → 编码 PNG 字节 → `ipc::Response` → 前端 Blob URL | 一次解码，前端复用 |
| 动画 | Rust 拆帧 → 帧字节序列 + 每帧延迟 → 前端 canvas 逐帧绘制 | 支持播放/暂停/逐帧步进 |

### 8.4 图片变换（纯前端）

- 缩放/平移：CSS `transform: translate() scale()`，GPU 加速，60fps
- 旋转/翻转：CSS `rotate() scaleX(-1)` 组合矩阵
- 状态机：`{ scale, x, y, rotation, flipH, flipV, fitMode }`，切图时重置
- 滚轮缩放以鼠标位置为锚点：标准公式 `newPos = mouse - (mouse - pos) * (newScale / scale)`

### 8.5 毛玻璃 UI 实现

```css
.toolbar {
    background: rgba(30, 30, 30, 0.55);
    backdrop-filter: blur(20px) saturate(1.4);
    border-radius: 12px;
    border: 1px solid rgba(255, 255, 255, 0.08);
    transition: opacity 180ms ease, transform 180ms ease;
}
```

- 工具栏闲置 2s 自动淡出，鼠标移动唤醒
- 沉浸模式下全部隐藏，仅保留 Esc 退出

### 8.6 快捷键实现

前端全局 `keydown` 监听 → 快捷键映射表 → 本地执行（变换类）或调用 Tauri command（翻页类）。无需可配置化，映射表硬编码，后续扩展容易。

### 8.7 文件关联与右键菜单

- `tauri.conf.json` → `bundle.fileAssociations`：声明支持的扩展名，NSIS 安装器自动注册
- 右键菜单：NSIS 安装脚本写入注册表 `HKEY_CLASSES_ROOT\*\shell\ZViewer`（由 Tauri bundle 的 NSIS 模板扩展实现）
- 启动参数：主进程接收 `std::env::args()` 中的图片路径，定位后初始化浏览模型

### 8.8 窗口控制

- 沉浸模式：`set_fullscreen(true)` + 隐藏前端 UI；Esc 恢复
- 置顶：`set_always_on_top(true)`
- 主窗口默认 `decorations: false` 自绘标题栏（配合毛玻璃风格统一）

## 9. 项目结构

采用 Tauri 官方常规目录结构：`src-tauri/` 存放 Rust 后端代码，`src/` 存放前端代码，**pnpm** 作为前端包管理器。

具体目录结构与常用开发/构建命令以 `README.md` 的「目录结构」「开发」「构建」节为准（单一事实来源，本文不再重复维护）。

## 11. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| `rawler` 对个别 RAW 格式覆盖不足 | 某些相机文件打不开 | 降级显示内嵌 JPEG 预览（RAW 文件通常内嵌），或切换 libraw-rs |
| 超大图（>1 亿像素）解码内存爆炸 | 卡顿/崩溃 | 解码前探测尺寸，超限自动降采样 |
| WebView2 `backdrop-filter` 性能 | 低端机掉帧 | 提供降级方案：降低模糊半径或改半透明纯色 |
| 用户机器无 WebView2 运行时 | 无法启动 | NSIS 安装器自动检测并引导安装（Tauri 内置支持） |
