# Image Viewer 看图观感优化报告（第一梯队）

> 优化范围：纯前端 5 项看图观感改进（渲染质量 / 适应策略 / 背景 / 反馈 / 切图过渡）
> 验证情况：`tsc` 类型检查 + `vite build` 通过；Rust 端零改动（CI `cargo test` 不受影响）
> 报告日期：2026-08-17
> 状态：代码全部落地，待实机走查验证清单（见文末）
> 定位约束：用户只想要**最简单的看图观感**——本轮只做每次看图都受益的打磨，
> 不引入管理类功能（缩略图墙 / 收藏 / 编辑等明确不做）

## 总结

围绕「打开每张图的第一眼和翻页的每一瞬间」做五个小而确定的改进：

1. **小图不再被"适应窗口"放大糊化** —— fit 倍率封顶 1×，小图原尺寸居中
2. **放大超过 100% 时像素级清晰渲染** —— `image-rendering: pixelated`，看像素不再是糊的
3. **信息条新增实时缩放百分比** —— 缩放/旋转/改窗口大小都即时同步
4. **B 键循环看图背景（黑 → 白 → 灰 → 棋盘格）** —— 深色透明素材不再隐形，选择持久化
5. **切图 150ms 交叉淡化（crossfade）** —— 旧画面快照冻结到新图就绪，翻页无黑屏跳变
6. **RAW/动画解码中指示** —— IPC 通道解码超过 300ms 时右上角显示"解码中…"转圈

## 改动明细

### ① fit 封顶 1×：小图不放大

- 位置：`src/viewer.ts` `fit()`
- **改动前**：`baseScale = min(availW/ew, availH/eh)`，无封顶——一张 200×200 的图标在
  4K 全屏被拉伸近 5 倍，糊成一团。
- **改动后**：`min(availW/ew, availH/eh, 1)`。小图原尺寸居中，大图照常缩小适应；
  想放大看细节用滚轮/双击（1:1）。
- **行为语义**：对小图而言 fit 与 1:1 显示效果相同（都是 100%），双击切换不再有视觉变化，属预期。
- **连带效应**：小图周围露出看图背景 → 与 ④ 背景切换形成配合。

### ② 放大 >100% 像素级清晰渲染

- 位置：`src/viewer.ts` `apply()`
- **改动**：显示倍率 `s > 1` 时给当前渲染元素（`<img>` 或动画 `<canvas>`）设置
  `image-rendering: pixelated`（最近邻），≤100% 恢复浏览器默认平滑。
- **原因**：缩小必须平滑（最近邻缩小失真严重），放大必须最近邻（双线性会把像素糊成雾）。
  照片 100% 检视、像素画、扫描文字均受益。
- **取舍**：不做开关——两类场景的正确行为由倍率唯一决定，没有用户偏好空间。

### ③ 信息条实时缩放百分比

- 位置：`index.html`（`#info-zoom`，位于文件大小与位置计数之间）、`src/ui.ts` `setZoom()`、
  `src/main.ts` `syncZoomButtons()`
- **行为**：显示 `Math.round(currentScale × 100)%`；无图片/未加载显示 `—`。
  触发链统一走 `viewer.onStateChange`，本轮补齐了两个此前不触发的场景：
  - `rotate()`：fit 态旋转 90/270 宽高互换 → fit 倍率变化；
  - `onResize()`：窗口尺寸变化 → fit 倍率变化。
- 样式并入 `.info-dims / .info-size / .info-pos` 同组（tabular-nums + 次级色）。

### ④ B 键循环看图背景（黑/白/灰/棋盘格）

- 位置：新建 `src/background.ts`（循环逻辑 + localStorage 持久化）、`src/input.ts`（B 键）、
  `src/ui.css`（`#stage.bg-white / bg-gray / bg-checker` 样式）、`src/main.ts`（Toast + 启动恢复）
- **动机**：看图区默认纯黑，深色透明素材（logo / 图标 PNG）在黑底上几乎不可见。
- **行为**：
  - B 键循环 黑 → 白 → 灰 → 棋盘格 → 黑，Toast 提示当前档位；
  - 选择持久化到 `localStorage["bg-style"]`，启动时恢复，非法值回退黑色；
  - 棋盘格 16px 双三角纹理（背景色 #7f7f7f + #9c9c9c），判断透明区域用；
  - 浅色背景下空状态文字自动切换为深色保持可读。
- **键位策略**：与 R/H/V 一致——纯键盘命令，不唤醒浮层。

### ⑤ 切图交叉淡化（crossfade 快照层）

- 位置：`index.html`（`#ghost-canvas`）、`src/viewer.ts`（`captureGhost()` / `releaseGhost()`）、
  `src/ui.css`
- **改动前**：切图时旧图立即消失 →（黑屏/空窗期）→ 新图 150ms 淡入。asset 快通道空窗期
  短，RAW/动画通道空窗期前虽有旧图垫底，但 `loadStatic` 一执行立刻跳黑。
- **改动后**：
  1. 每次加载新图**之前**，把当前画面（含缩放/旋转/翻转变换）按设备像素比 1:1 重绘到
     快照层 `<canvas id="ghost-canvas">`（位于 image/frame-canvas 之上）；
  2. 旧元素被隐藏/换源期间，用户看到的仍是快照——画面完全静止、无跳变；
  3. 新图解码完成 → 快照淡出、新图淡入（同用 `--t-image` 150ms）→ 交叉淡化；
  4. 淡出完成后快照画布置零尺寸，释放整屏位图内存。
- **实现要点**：
  - `captureGhost()` 复刻 `apply()` 的变换链（translate → rotate → scale → 居中偏移），
    `drawImage` 到 viewport×DPR 尺寸画布，设备像素精确映射；
  - 画 asset 协议图会 taint 画布，但快照仅作显示、绝不回读像素，无碍；
  - 加载失败路径（`handleError` / 动画帧解码失败）显式释放快照，回到黑底 + Toast，
    不留永久冻结的旧画面；
  - 连续快速翻页：新一次 capture 会覆盖旧快照并接管制表计时，无泄漏。
- **取舍**：快照期间画面冻结（拖拽平移无反馈）——解码空窗期本就无法交互新图，
  冻结旧画面优于黑屏，且 asset 快通道空窗期通常 <100ms。

### ⑥ RAW/动画解码中指示

- 位置：`index.html`（`#decoding` 玻璃浮片 + 转圈动画）、`src/ui.ts`
  （`beginDecoding()` / `endDecoding()`）、`src/main.ts`（IPC 分支包裹）
- **动机**：RAW 解码常见 2.5s+（`main.ts` 幻灯片注释自述），此前无任何反馈。
- **行为**：
  - 仅 IPC 通道（RAW/动画 `load_image`）触发；asset 快通道不显示（浏览器解码快且预取已预热）；
  - **防抖 300ms**：短解码不闪现（`DECODE_SHOW_DELAY_MS`），归零立即隐藏；
  - **引用计数**：并发加载（幻灯片 5s 兜底 + 手动翻页竞态）各自 begin/end，计数归零才隐藏；
  - 位置右上角（标题栏下方 16px，沉浸模式贴顶 16px），不与居中的 Toast/工具栏冲突；
  - 计数与快照层正交：指示的是"Rust 在解"，快照负责"画面不跳"。

## 明确不做（与「最简单看图」相悖）

缩略图网格/文件管理器、标签收藏、裁剪编辑、批量重命名、云同步、AI 识图、视频播放、
平滑缩放动画（zoom 缓动易引入迟滞感）。

## 后续梯队（已分析、本轮未做）

- **第二梯队**：鼠标侧键翻页（XBUTTON1/2）、缩放锁定跨图保持、最小文件操作集
  （Ctrl+C 复制到剪贴板 / 复制文件 / 打开所在文件夹 / Delete 删到回收站）、
  按需 EXIF 浮层（I 键）
- **第三梯队**：AVIF 扩展名接入（WebView2 原生解码，近乎一行）、TIFF 走 Rust 解码通道、
  `tauri-plugin-window-state` 窗口几何记忆
- **待核查**：动画通道 Rust 拆帧重编码 PNG 会丢 EXIF 方向，APNG/动态 WebP 带方向
  标记的文件可能躺倒显示，需实机验证

## 手动验证清单

- [ ] 打开小于窗口的图片（如图标）：原尺寸居中显示，信息条缩放 100%
- [ ] 滚轮放大到 >100%：像素颗粒清晰（非糊状）；缩回 ≤100% 恢复平滑
- [ ] 缩放/旋转（fit 态 R 键）/ 拖拽改窗口大小：信息条百分比即时变化
- [ ] B 键连续按 4 次：黑 → 白 → 灰 → 棋盘格循环，Toast 提示档位；重启应用后保持
- [ ] 棋盘格/白底下空状态（未打开图片）文字仍可读
- [ ] 深色透明 PNG：黑底不可见 → B 切白底/棋盘格后清晰可见
- [ ] 快速 ←/→ 连续翻页：无黑屏闪烁，旧图平滑过渡到新图
- [ ] 打开大 RAW（首次无缓存）：右上角 >300ms 后出现"解码中…"，完成后消失
- [ ] 幻灯片播放到 RAW：解码指示与进度计数正常，无重叠遮挡
- [ ] 解码失败（损坏文件）：Toast 报错，画面回黑底，无冻结残影
