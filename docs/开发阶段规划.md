# ZViewer 开发阶段规划

> 里程碑追踪文档。各阶段施工依据详见《需求报告与技术方案.md》与《UI设计草图.md》。

## 阶段总览

| 阶段 | 内容 | 验收标准 |
|------|------|----------|
| **M1 核心浏览** | Tauri 骨架、常见格式显示、方向键翻页、系统顺序、跨文件夹无缝衔接、边界 Toast | 双击图片打开，←/→ 流畅翻页跨文件夹 |
| **M2 变换与 UI** | 滚轮缩放、旋转翻转、1:1/适应窗口、毛玻璃工具栏与信息条、自绘标题栏 | UI 风格达标，变换 60fps |
| **M3 格式扩展** | RAW 解码（rawler）、动画逐帧控制 | CR2/NEF/ARW/DNG 可打开，GIF 可逐帧 |
| **M4 体验完善** | 幻灯片、预加载缓存优化、无边框沉浸模式、窗口置顶 | 切换 ≤50ms，幻灯片可调间隔 |
| **M5 发布** | 文件关联、右键菜单、NSIS 安装包、图标与品牌打磨 | 安装后双击图片默认打开 |

## 功能候选（未排期）

已分析、尚未排期的改进点（不改变「最简单看图」定位，与需求报告 §5「明确不做」不冲突）：

- 缩放锁定跨图保持
- 最小文件操作集：Ctrl+C 复制到剪贴板 / 复制文件 / 打开所在文件夹 / Delete 删到回收站
- 按需 EXIF 浮层（I 键）
- 窗口几何记忆（`tauri-plugin-window-state`）
- 待核查：动画通道 Rust 拆帧重编码 PNG 会丢 EXIF 方向，APNG/动态 WebP 带方向标记的文件可能躺倒显示，需实机验证
