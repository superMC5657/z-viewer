# ADR 0003：跨文件夹浏览开放至免费版

日期：2026-10-24
状态：已采纳

## 背景

ADR 0002 把「跨同级文件夹无缝浏览 + 文件夹跳转」划为专业版功能，并自认
「免费版体验不到核心卖点」——需求文档初版的核心特色成为付费墙后的功能，
口碑传播失去支点。同日的翻页延迟基准（票 02）进一步显示：免费档的「卡」
根源在重格式解码流水线（冷翻 p50 1.1–1.4s），而非缺少跨文件夹能力本身；
即使专业版，预取也追不上冷解码（专1 正常节奏命中率仅 53–60%）。
跨文件夹作为付费点，既伤害传播，又换不来强转化理由。

## 决策（2026-10-24）

1. **跨同级文件夹无缝浏览与文件夹跳转（`jump_folder` / PageUp/PageDown）
   开放至免费版**，全版本可用。
2. **预取缓存（等级 1/2，队列 A/B 与前端预热池）维持专业版**，成为当前
   唯一的付费功能点；其定位与边界待票 03 裁决（基础窗口是否下放）。
3. 免费版跨文件夹边界翻页为冷解码（无预取），属已知体验边界；
   解码流水线提速 / 预览先显另行立项。

## 落地（按 ADR 0002 后果条款同步三处 + 门控代码）

- 门控代码：`browse/scan.rs` 移除 `cross_folder` 参数（`open_gated` → `open`、
  `open_first_in_dir_gated` → `open_first_in_dir`）；`commands::jump_folder`
  摘除 `require_pro`；`NavResult::pro_required` 移除（前端 `pro-required`
  管道保留作防御深度，当前无生产者）。
- 打开拒绝日志 `browse open gated reject` → `browse open reject`（logging.md 同步）。
- 需求文档 1/2.2/2.8/8.2、README 功能总览、开发阶段规划同步。

## 后果

- 免费版恢复需求文档初版的核心特色，口碑/传播路径重新成立。
- 付费价值点收敛至预取缓存单项；若票 03 决定下放基础缓存，须新立 ADR
  重新定义专业版卖点（候选：解码提速、新格式、云同步等——需另行论证）。
- ADR 0002 决策 1/2 由本 ADR 部分取代；授权体系（决策 3）与埋点（决策 4）不变。
