# ADR 0002：免费版/专业版分层——跨文件夹浏览与预取缓存为专业版功能

日期：2026-10-24
状态：已采纳；决策 2 的「跨文件夹浏览与文件夹跳转为专业版」部分已被 ADR 0003 取代（2026-10-24）

## 背景

《需求报告与技术方案.md》初版（2.2「核心特色」）把「跨同级文件夹无缝浏览」列为
无分层的核心功能，通篇没有免费/付费之分。实现随《开发阶段规划.md》走向商业化后，
出现三处缺正式决策记录的行为：

1. 跨文件夹浏览（翻页无缝跨文件夹 + PageUp/PageDown 跳文件夹）在免费版整体禁用：
   `browse/scan.rs` 的 `open_gated(cross_folder=false)` 不枚举兄弟文件夹，
   `jump_folder` 返回 `pro-required`（前端弹解锁引导）。
2. 预取缓存免费版锁定关闭（`set_cache_level` 拒绝、容量归零、前端按钮锁定）。
3. 配套体系无规格依据：`license.rs`（Ed25519 JWT 验签、设备指纹、在线续验、
   激活/注销对话框）与 `analytics.rs`（聚合埋点上报）。

2026-10-24 code review 的 Spec 轴把「核心特色被付费门控、需求文档无付费之分」
列为最重发现；本 ADR 补上缺失的决策记录。

## 决策（2026-10-24 复核，维持现状）

1. **免费版**：单文件夹浏览；全部变换/快捷键/幻灯片/动画逐帧/解码通道可用。
2. **专业版**（soft-candy 在线激活码解锁）：跨同级文件夹无缝浏览与文件夹跳转、
   预取缓存（等级 1/2）。与 README「功能总览」和《开发阶段规划.md》一致。
3. **授权体系形态维持**：Ed25519 JWT 本地验签 + 设备指纹 + 在线续验
   （吊销生效删凭证，网络失败走离线宽限期，不误伤付费用户）。
4. **埋点不加告知与开关**（产品裁决 2026-10-24）：上报内容经确认为非敏感聚合
   统计（设备 ID、授权状态、浏览计数、格式/文件夹分布），无路径、无图片内容。
5. 需求文档 2.2/2.8 同步标注分层归属，消除「规格无付费、代码有付费墙」的矛盾。

## 后果

- 需求文档、README、实现三者一致；后续 review 的 Spec 轴不再报此矛盾。
- 免费版体验不到核心卖点，转化路径依赖 `pro-required` → 解锁引导弹窗。
- 若未来调整分层边界（如跨文件夹改免费），须新立 ADR 并同步需求文档、
  README、门控代码（`open_gated` / `jump_folder` / `set_cache_level`）三处。
