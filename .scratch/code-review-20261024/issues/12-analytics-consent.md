# 12. 埋点上报的用户告知与开关(合规)

Status: wontfix
Source: code review 2026-10-24, Spec 轴 scope creep #2
Severity: P1(合规风险,建议优先于其他决策项)

## 问题

`src-tauri/src/analytics.rs`(330 行)在退出时向远端 POST 设备 ID、授权状态、浏览次数、格式/文件夹分布,带 Bearer token;无用户告知、无开关,三份规格均无此需求。若产品在中国大陆/欧盟分发,涉及 PIPL/GDPR 的告知同意与最小化要求。

## 决策三选一

- (a) 首启明示 + 设置页开关(默认关或默认开,由法务/产品定),未同意不上报。
- (b) 保留但最小化:去设备 ID 改随机匿名 ID、字段裁剪、默认可关,并在隐私说明中列明上报内容。
- (c) 直接移除上报模块。

## 建议

无论选哪个:上报字段清单写进隐私说明/README;上报失败静默重试逻辑要有上限;实现工作可在此票裁决后拆给 agent。

## 验收

- 用户可感知、可控(或已移除);文档与实际上报内容一致;退出口径与 ADR 0002 一致。

## Comments

- 2026-10-24 裁决（产品负责人）：上报内容经确认为非敏感信息，**不做处理**——不加告知/开关，不匿名化，不移除。该决定已记录于 ADR 0002 决策第 4 条。
