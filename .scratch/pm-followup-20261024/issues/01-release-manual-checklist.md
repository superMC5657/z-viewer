# 01. 发版前手验清单(发布门槛)

Status: ready-for-human
Source: 产品视角复盘(发布视角);code review 20261024 中被顺延的手验项(票05/06/09/10)
Type: task

## 背景

票 05/06/09/10 的验收中有一批「下次打包时确认」的手验项,它们恰好全是用户第一次接触产品的时刻(安装→关联→双击打开;重启→设置还在)。这类项永远不会被自动化覆盖,必须固化为发版门槛,而不是顺延。

## 清单(逐项打勾,全部通过才可发版)

- [ ] **A. 安装/关联**:安装包安装成功;右键「打开方式」出现 ZViewer,AVIF/JXL 可选;双击 AVIF/JXL/RAW 直达打开;卸载后关联无残留、开始菜单/桌面快捷方式清理干净〔票09〕
- [ ] **B. 幻灯片**:自定义间隔 1s 与 3600s 边界生效;非法输入(0/负数/超大)取消路径回显不崩;重启后固定档位与自定义值均保留〔票10〕
- [ ] **C. 动画**:gif/webp 动画 ↔ 静态图来回切换 ≥10 次,无帧残留、无闪烁、无内存攀升;动画播放中切图/关窗无报错〔票06〕
- [ ] **D. 快翻**:大文件夹(≥500 张,含 RAW)连续快翻 50+,内存平稳、无卡顿累积〔票05〕
- [ ] **E. 门控体验**:免费版翻页跨文件夹边界出现解锁引导(而非报错/静默失败);激活后立即解锁;`pro-required` 弹窗文案与购买跳转可达
- [ ] **F. 授权**:激活成功/失败、注销、离线宽限期提示各走一遍
- [ ] **G. 日志/诊断**:导出诊断包,抽查 zip 内无全路径、无 email/token/激活码(crash 报告仅 dev 构建产生,dev 包抽查即可)
- [ ] **H. 更新**:「检查更新→已是最新」分支正常
- [ ] **I. 自动门禁**:CI 绿(fmt/clippy/test,tsc 经 pnpm build)——发布流水线已覆盖,此处只确认

## 验收

- 清单逐项打勾后本票 resolved;任何一项失败 → 新立 bug 票并标注发版阻塞。
