# 03. 裁决:预取缓存分层(免费版保留多少)

Status: ready-for-human
Blocked by: 02
Source: 产品视角复盘(战略视角);ADR 0002 决策 2,经 ADR 0003 重新框定
Type: grilling

## 决策点

ADR 0003(2026-10-24)已把跨文件夹浏览开放至免费版,**预取缓存(等级 1/2)
成为当前唯一付费功能点**。基于票 02 的延迟数据,裁决免费版保留多少缓存。

## 选项

- **A. 维持现状**:免费零预取,专业版独占缓存(前1后1/前1后3 + 队列 A 首图)。
  转化抓手最纯粹;但票 02 显示专业档命中率也仅 53–80%(冷解码 > 翻页间隔,
  预取追不上),卖点成色存疑。
- **B. 免费版给单文件夹内小窗口**(如 level1「前1后1」),更大窗口与
  跨文件夹首图队列维持专业版。免费核心循环保住「不卡」下限;但付费差异变薄。
- **C. 缓存全免费**:付费点悬空,须另立卖点(解码提速/新格式/云同步),短期不建议。

## 建议

票 02 关键输入:瓶颈在解码流水线而非缓存结构(冷翻 p50 1.1–1.4s,命中后 10–13ms)。
倾向:**先立项「解码提速 / 非 RAW 通道预览先显」把冷翻压到感知线内,缓存分层维持 A**;
待解码提速落地后再评估 B/C——否则任何分层都是在「卡」与「不卡」之间挪门槛,
付费点立在一个连专业版都兑现不了的承诺上。
无论选哪项:按 ADR 0002 后果条款同步需求文档、README、门控代码(`set_cache_level`)三处,
必要时新立 ADR。
